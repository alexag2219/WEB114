Javascript Questions

1. Why is textContent safer than innerHTML?

Answer: textContent is safer as it deals with plain text, making it safer when input might not be trusted.

2. How are HTML elements connected to JavaScript variables using DOM selection?

Answer: The HTML elements are connected to JavaScript variables using DOM selection by using the element ID.

3. What would happen to the text box with id="text" if I added this line to the code above it: text.textConent = "Hello!"

Answer: If you added the line of code above it would change the content that goes along with the element id="text."
